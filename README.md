# Webカメラのフェイストラッキングによる立体視デモシステム

## 概要
Webカメラを用いてユーザーの顔をトラッキングし、モニターの奥に空間があるように錯覚させる立体視（Portalgraph風）システムです。
Python側で取得した目の位置をUDP通信でUnityへ送信し、モニターを「窓」とみなした投影（Off-Axis Projection）でリアルタイムに描画することで、没入感の高い疑似3D体験を実現しました。

## 動画[https://youtu.be/KINKttTQQCA]

## システム構成
- **顔認識・データ送信**: Python (OpenCV + MediaPipe Face Mesh)
- **3D環境・描画**: Unity (C# / URP)
- **通信プロトコル**: UDPソケット通信 (ローカルネットワーク)

## 主要な機能
- **目の位置の3次元推定**: MediaPipe の虹彩ランドマークから両目の中点を求め、瞳孔間距離とピンホールカメラモデルでWebカメラからの位置（メートル）を計算します。顔を左右に向けても距離が暴れないよう、ランドマークの奥行きも含めて目の間隔を測っています。
- **焦点距離のキャリブレーション**: 決まった距離（50cm）に座って C キーを押すだけで、Webカメラの焦点距離を逆算して保存します。
- **Off-Axis Projection**: 現実のモニターの実寸と目の位置から、目→モニター四隅を通る歪んだ視錐台を毎フレーム計算し、モニターの向こうに空間があるように描画します。
- **前後移動のモード切替**: 本物の窓と同じ見え方の `Window` と、画角を固定してカメラを前後に動かす `Dolly` を切り替えられます。
- **低遅延の受信と平滑化**: UDPを別スレッドで受信し、One Euro Filter で「静止時のブレ」と「動いたときの遅延」を両立させています。
- **ワールド座標グリッドシェーダー**: 壁のScaleを変えてもマス目の大きさが一定で、壁同士の線が角でつながる背景用シェーダー（`Assets/Grid/WorldGrid.shader`）。

## 環境構築

### Python側のセットアップ
仮想環境を作成し、必要なパッケージをインストールして実行準備を行います。

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 実行
1. `python tracker.py` を起動します。
2. 初回のみ、Webカメラから50cmの位置に座り、プレビュー画面で **C** キーを押してキャリブレーションします（`calib.json` に保存されます）。
3. Unity側を再生します（ビルドした場合は exe を起動し、Esc で終了）。

### Unity側のセットアップ
Main Camera に `UDPReceiver` と `OffAxisCamera` をアタッチし、インスペクターで以下を設定します。単位はすべてメートルです。
- **Screen Width / Height**: モニターの表示部分の実寸（例: 27インチ16:9 → 0.597 / 0.336）
- **Webcam Offset**: モニター中心から見たWebカメラの位置（上辺中央なら y ≈ 0.18）
- **World Scale**: 現実1mを何Unity単位にするか（大きいほどシーンがミニチュアに見える）
- **Screen**: モニター面の位置。空のオブジェクトを置き、青矢印(Z+)をシーンの奥へ向ける（未設定ならカメラの初期位置）

※ 3Dモデル・モーション・楽曲などの第三者アセットはリポジトリに含めていません。
